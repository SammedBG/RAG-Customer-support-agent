# TechNova SmartHome Hub — Product FAQ

## General

### What is the TechNova SmartHome Hub?
The TechNova SmartHome Hub is a centralized smart home controller that connects and manages all your IoT devices through a single, intuitive interface. It supports Zigbee, Z-Wave, Wi-Fi, Bluetooth 5.0, and Thread protocols, making it compatible with over 5,000 smart home devices from 200+ brands.

### What are the available models?
We offer three models:
- **SmartHome Hub Lite** ($79.99) — Supports up to 50 devices, Wi-Fi and Bluetooth only
- **SmartHome Hub Pro** ($149.99) — Supports up to 200 devices, all protocols, includes voice assistant
- **SmartHome Hub Enterprise** ($299.99) — Unlimited devices, all protocols, rack-mountable, 24/7 priority support

### What's included in the box?
Every SmartHome Hub ships with:
- SmartHome Hub unit
- USB-C power adapter (5V/3A)
- Ethernet cable (1m Cat6)
- Quick Start Guide
- Wall mount bracket and screws

## Features

### Does it work with voice assistants?
Yes! The SmartHome Hub Pro and Enterprise models include a built-in voice assistant called **NovaVoice**. All models are also compatible with Amazon Alexa, Google Assistant, and Apple HomeKit.

### Can I create automation routines?
Absolutely. Our **NovaFlow** automation engine lets you create complex routines:
- **Time-based triggers** — e.g., turn on lights at sunset
- **Device-based triggers** — e.g., when motion sensor activates, turn on camera
- **Condition-based logic** — e.g., only if home mode is "Away"
- **Multi-step sequences** — chain up to 25 actions in a single routine

### Does it support geofencing?
Yes, all models support geofencing through the TechNova mobile app. You can set up location-based automations like:
- Automatically arm the security system when you leave home
- Pre-heat the house when you're 10 minutes away
- Turn off all lights when everyone has left

## Compatibility

### Which smart lock brands are supported?
We support the following smart lock brands:
- August (all models)
- Yale (Assure Lock series)
- Schlage (Encode series)
- Kwikset (Halo series)
- Level (Bolt and Lock)
- Nuki (Smart Lock 3.0+)

### Is it compatible with solar panel systems?
The SmartHome Hub Pro and Enterprise can integrate with:
- **SolarEdge** — Full monitoring and automation
- **Enphase** — Energy production monitoring
- **Tesla Powerwall** — Battery level monitoring and load management
- **SunPower** — Basic monitoring via API

### What about legacy devices?
For devices using older protocols (X10, Insteon), we offer the **Legacy Bridge Adapter** ($39.99) that connects to the Hub via USB and translates legacy signals.
